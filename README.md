# Moto Tracker

GPS-трекер для поездок на мотоцикле: записывает маршрут и скорость, рисует
маршрут на карте Яндекса **плавным градиентом по скорости**, считает
расстояние, две средних скорости (в движении и общую), максимум, умеет
паузу на остановках (в том числе автопаузу), работает GPS-спидометром
и экспортирует поездки в GPX.

## Стек

- Kotlin + Jetpack Compose (Material 3), один модуль
- Yandex MapKit SDK 4.x (`com.yandex.android:maps.mobile`) — некоммерческое использование бесплатно
- Room (SQLite) — треки и точки, запись устойчива к сбоям (статистика пишется в БД каждые 5 с)
- Foreground Service + FusedLocationProvider (Google Play services) + WakeLock
- Минимальный Android 8.0 (API 26), целевой — Android 16 (API 36)

## Сборка

1. Установи **Android Studio** (JDK 17 идёт в комплекте).
2. Открой папку проекта.
3. Получи API-ключ MapKit (см. ниже) и впиши его в `local.properties`:

   ```properties
   MAPKIT_API_KEY=твой_ключ
   ```

4. Sync + Run на устройстве.

## Получение ключа Yandex MapKit (делается руками, один раз)

1. Зайди на **developer.tech.yandex.ru** под аккаунтом Яндекса.
2. «Подключить API» → **MapKit mobile** (для некоммерческого использования бесплатно).
3. Укажи package name: `com.mototracker.app`
   (если решишь сменить — поменяй `namespace`/`applicationId` в `app/build.gradle.kts` и обязательно переделай ключ).
4. Добавь SHA-1 отпечаток debug-ключа:

   ```bash
   keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android -keypass android
   ```

5. Скопируй полученный ключ в `local.properties` как `MAPKIT_API_KEY=...`.

Ключ не попадает в git — `.gitignore` уже исключает `local.properties`.

## Как пользоваться

- **Запись** — карта, сверху живая статистика, снизу большие кнопки СТАРТ/ПАУЗА/СТОП (удобно в перчатках). Во время записи экран не гаснет.
- **Спидометр** — полноэкранная цифра, цвет = текущая скорость на градиенте, плюс бейдж точности GPS (±м).
- **История** — список поездок; внутри — маршрут с раскраской, полная статистика, экспорт в GPX (сохраняется в «Загрузки» и сразу предлагается отправить) и удаление.
- **Настройки** — автопауза и её порог, чувствительность GPS-фильтра, «держать экран включённым», отключение оптимизации батареи.

## Плохой GPS (наш регион)

Рекордер отбраковывает:

- точки с точностью хуже порога из настроек (по умолчанию 30 м);
- «телепорты» — перемещения, подразумевающие скорость выше правдоподобной (250 км/ч по умолчанию);
- протухшие фикс-ы (старше 8 с) и точки «из будущего»;
- шум на стоянке (адаптивный порог по точности соседних фикс-ов — дистанция не «накручивается» на светофорах).

Если маршрут в твоих местах рвётся — подними порог точности до 40–50 м в настройках.
Скорость берётся преимущественно доплеровская (`location.speed`), она стабильнее координат, плюс сглаживание EMA.

## HyperOS/MIUI — чтобы не убивала запись

1. Приложения → Moto Tracker → **Автозапуск: вкл**
2. Экономия батареи → **«Нет ограничений»**
3. Зафиксируй приложение в «недавних» (долгий тап по карточке → замок)
4. Кнопка «Разрешить работу в фоне» в настройках приложения

## Известные ограничения / что можно добавить потом

- Камера не «вписывает» весь маршрут в экран (центрируется на старте) — автоfit в планах.
- Линия маршрута пересобирается целиком на каждую точку; при треках >4000 точек включается прореживание.
- Нет офлайн-карт: тайлы Яндекса кешируются частично; в глухих зонах карта может не прогрузиться (запись GPS при этом не прерывается — точки пишутся всегда).
- Градиент скорости захардкожен (0→200+ км/ч, зелёный→пурпурный) — легко вынести в настройки.
